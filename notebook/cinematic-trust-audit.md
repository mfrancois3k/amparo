- Both new privacy pages explain local practice data, supervision answers, browser/device voice processing, optional Clerk/Convex accounts, pack deletion versus device deletion, disabled marketing metrics, Sentry diagnostics/feedback and disabled payments with Stripe configured for future use.
- Pack and aid PostHog bootstraps and first-touch campaign collection were removed. Existing optional event wrappers are preserved as no-ops without an SDK. The parent task owns homepage tracker removal. Prior attribution already saved in a browser is not proactively erased by this change.
- Arena asks why supervision information matters and explains local storage before either answer is saved. The existing yes/no decision, warnings and held door-practice gate are unchanged. A new “prefer not to say” behavior was not invented because choosing an alternate coaching path requires review.
- Arena privacy now discloses automatic technical-error reporting. Its former blanket “uploads nothing” and “no third party” wording was inaccurate. The hidden avatar no longer claims Amparo has no accounts. Wipe copy is scoped to the practice/setup save actually removed, rather than every local record.
- Arena organization CTA goes to the real organizations page with language retained. Pack privacy is mirrored into `app-src/src/content/t.en.json` and `t.es.json` by the existing extractor.

## Implementation findings

`arena/index.html` saves the `A` object under `amparoArena`; `A.hist` contains response history. The supervision buttons set `A.sup` and `A.asked`, then call `saveA()`. The wipe handler removes `amparoArena` and `amparoGuidedFlow`; it does not delete downloaded files, the separate pack, cloud records or entitlement records.

`app-src/convex/packs.ts` accepts state, name, emergency-contact fields, attorney contact, ZIP and language, linked to authenticated user identity. It has a separate cloud removal mutation. Photo and practice-history fields are absent from this pack schema.

`tools/sentry-entry.js` enables diagnostic errors and voluntary feedback; no tracing, replay or screenshot integration is enabled. It removes request data, query/hash, cookies and user identity from error events, strips URL parameters from feedback and drops input breadcrumbs. The host shims automatically flush technical errors. Sentry remains functional and explicitly disclosed; this is not a claim of zero network traffic or guaranteed anonymity of arbitrary exception messages. Feedback content is whatever the user submits.

Repository tracker search found active PostHog in the homepage, pack and aid pages, plus an already-disabled Arena bootstrap. Marketing vendor names also occur in archived reports, configuration allowlists and dependencies; those references alone are not active collection. The parent task owns final whole-site runtime network verification and CSP changes.
