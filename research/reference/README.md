# Reference datasets (Base44-sourced, UNVERIFIED)

These five files are derivative content built on top of the Job 1-8 statute research --
plain-language summaries, an officer checklist, a defense playbook, recording/refusal
rights, and a complaint directory. None have been through this project's own
fetch-and-read verification. Their accuracy is bounded by (a) whatever underlying
statute cells they cite, most of which ARE cells already verified in state-matrix.md,
and (b) added claims -- refusal penalties, recording consent law, POST council URLs,
S.1983 statutes of limitations -- that this project has never independently checked.

Do not treat anything in this folder as ground truth for a shipped feature. Treat it as
a draft worth verifying before use, in the same way every other Base44 locator claim
in this project has been treated.
